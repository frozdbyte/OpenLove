Self-host it

Open Love ships as a single container with a bundled SQLite database — no external services to wire up. Pick whichever fits how you already run things.

🐳 Docker Compose

Run it anywhere Docker runs — a VPS, a home server, or your laptop.

git clone https://github.com/frozdbyte/OpenLove.git
cd OpenLove
docker compose up -d

Open http://localhost:3000 to start the onboarding wizard.

SQLite data and auto-generated VAPID push keys persist in the openlove_data volume.

☁️ Coolify

Open Love ships a ready-made compose file for Coolify's one-click deploys.

  1. In Coolify, create a new Docker Compose service.
  2. Point it at this repository, or paste the contents of docker-compose.coolify.yml.
  3. Set your domain in the Coolify UI — SERVICE_FQDN_OPENLOVE_3000 wires it up automatically.
  4. Deploy. Coolify handles SSL, the reverse proxy, and restarts.

VAPID push keys auto-generate into /app/data/vapid.json on first boot — or set your own via PUBLIC_VAPID_KEY / PRIVATE_VAPID_KEY / VAPID_SUBJECT in Coolify's environment tab.

See the README for the full environment variable reference and privacy architecture.
